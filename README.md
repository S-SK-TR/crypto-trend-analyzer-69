# crypto-trend-analyzer-69
Bitcoin ve diğer kripto paraların piyasa analizini sağlayan bir dijital platform. Kullanıcıların piyasa trendlerini takip etmelerini, analiz raporlarını oluşturmalarını ve stratejilerini yönetmelerini sağlayan bir sistem. Modern UI/UX prensipleriyle tasarlanmış olup, Vite, React, TypeScript, Tailwind CSS, Lucide React ve Framer Motion kullanılar...
